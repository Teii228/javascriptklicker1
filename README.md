# javascriptklicker1
Hej. Det är min klicker spel för js projekten. Det är bara att klicka på knappen. Först, det börjar med litet introt ( jag vet inte varför den finns fortfarande, jag var latt att ta bort den ), och sen efter introt kommer ordentligt spel.
Från 5 poäng öppnas affären med olika uppgraderingar. Från början det finns bara en uppgradering, men andra öppnas genom att uppgradera den sista möjligt. Det finns lite olika speciela skämt grejer, men hoppas att det är lugnt.
Det finns inget balans i spelet, så uppgraderinga kan vara jättelätta att uppnå, fast priserna är galen.
Rekommenderas att använda autoclicker. Annars dör man.
